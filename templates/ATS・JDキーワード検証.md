# ATS・JDキーワード検証

> いつ使うか: JD定制済みの書類をPDF化した直後、提出前。これはキーワード詰め込みのためではなく、PDFの文字層と、事実に基づくJD語彙の採用状況を確認するための記録。

## 手順

1. `pdftotext -layout <PDF> -` または `pypdf` で、対象PDFから文字を抽出する。
2. 氏名・連絡先・見出し・主要実績が抽出できること、文字化け・制御文字がないことを確認する。
3. JDから必須・主要語を選び、本文に根拠付きで入っているかを記録する。未経験の語は、無理に入れず「ギャップ」とする。
4. 結果を `documents/output/{接尾辞}/md/ATS・JDキーワード検証_{接尾辞}.md` に残す。

## 記録テンプレート

| JD語 | 優先度 | 本文での状態（記載あり／同義語／意図的に未記載） | 根拠・掲載箇所 | 判定 |
|---|---|---|---|---|
| {{キーワード}} | 必須／主要／歓迎 | | | |

### 文字層チェック

- [ ] 氏名と連絡先が抽出できる
- [ ] 主な見出しが抽出できる
- [ ] 制御文字・文字化けがない
- [ ] ページ数・目視レイアウトを確認した
