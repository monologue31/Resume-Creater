## このモジュールが解決すること

「いくら希望すればいいか」を勘や願望で決めず、**市場データと自分の実績規模を根拠にした3段階の目標設定**にする。あわせて、外資系特有の**OTE（On-Target Earnings）とbaseの混同**、**現年収の開示方針**を整理する。

## 進め方

1. **市場データを集める**: 公開求人のレンジ、同等ポジション・グレードの相場。可能なら複数ソースで裏取りする
2. **現年収を正確に把握する**: base・賞与・インセンティブを分けて把握する。直近の昇給・昇格があれば、古い数字と混同しない（教訓6と同じ問題がここでも起きる）
3. **3段階を設定する**:
   - **最低ライン**: これを下回るなら受ける意味が薄い、という下限。機械的な「現年収 × 1.2」等の換算だけでなく、転職に伴うリスク（業種変更、外資特有の定着リスク等）を踏まえて据え置くこともある
   - **本命（現実的な着地点）**: 市場レンジの中で、自分の実績・資格が評価された場合に乗ると想定する水準
   - **強気**: 交渉の初期提示や、条件が特に良い場合の上振れ余地
4. **OTEとbaseを区別する**: 求人票に書かれた金額がOTE（インセンティブ込みの目標到達額）なのかbase（基本給）なのかを必ず確認し、区別して記録する。区別せずに希望額を出すと、比較対象を誤る
5. **開示方針を決める**: 現年収を聞かれた場合、正直に伝える方針を基本とする（源泉徴収票の提出を求められることがあり、虚偽は内定取消につながり得る）。直近の昇給・昇格があれば、それをポジティブな材料として伝える

## 使うときの注意

- **希望額は「言い値」ではなく、市場データ・実績規模のどちらかに必ず紐づけて記録する。** 根拠が無い希望額は、面接官に「なぜその金額か」と聞かれたときに崩れる
- **最低ラインは低く見積もりすぎない。** 「下回るなら受ける意味が薄い」という基準を、機械的な換算だけで甘く設定しないこと（業種変更・外資転職特有のリスクを加味する）
