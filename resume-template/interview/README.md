# interview フォルダ

応募先ごとに**選考の進行を管理し、各ラウンドの記録を残す**ためのフォルダです。
書類（`documents/`）と同じ `input/` を読むため、面接の回答が書類と食い違うことがありません。

```
interview/
├── 選考一覧.md              全応募先の横断ダッシュボード。まずここを見る
├── INTERVIEW_PROMPT.md      想定質問・自己紹介の生成プロンプト
├── _template/               新しい応募先を作るときの雛形
│   ├── 選考状況.md
│   └── ラウンド記録.md
└── companies/
    └── {応募先}/             新しい応募先を追加するたびに `_template/` からコピーして作る
        ├── 選考状況.md       このポジションの全体像とフロー
        └── rounds/          ラウンドごとの準備メモ＋実施後の記録
```

## 中心にある考え方

**各ラウンドの記録が、次のラウンドの準備の材料になる。**

選考が進むほど、面接官は前のラウンドの記録を見ながら話します。
1次で言ったことと3次で言うことがズレると、それだけで落ちます。
だから `rounds/` の各ファイルは、上半分が「事前準備」、下半分が「実施後の記録」という構成になっています。

> **面接が終わったら30分以内に下半分を埋めてください。**1日経つと細部が消えます。
> ここが空だと、次のラウンドの想定質問が「一般論」になってしまい、価値が半分以下になります。

## 使い方

### 新しい応募先を追加する
「◯◯社の選考を管理したい」と言えば、`_template/` から `companies/◯◯/` を作ります。
選考フロー（何次まであるか、誰が出るか、課題の有無）を教えてもらえれば、ラウンドごとのファイルまで用意します。

### 面接の準備をする
「◯◯社の△次の準備をして」と言うと、`rounds/` の該当ファイルと過去のラウンド記録を読んだうえで、
想定質問・自己紹介・想定される深掘りへの回答方針を、対象ラウンドの`rounds/{ラウンド}.md`に直接書き込みます（個別ファイルは生成しません。詳細は`INTERVIEW_PROMPT.md`参照）。

### 面接の記録を残す
「面接の記録を書きたい」と言えば、聞き取りながら該当ラウンドのファイルを埋めます。
自分で直接書き込んでも構いません。

### 全体を見る
`選考一覧.md` に全応募先の現在地と次のアクションがまとまっています。

## 面接官タイプの見分け方

| | 肩書の例 | 見ている軸 | 回答の重心 |
|---|---|---|---|
| 人事 | Talent Acquisition、採用担当 | 辞めないか、話が一貫しているか | 転職理由、志望度、条件。**技術は薄く** |
| 現場 | チームリード、マネージャー、シニア職 | 明日から戦力になるか | 案件の具体、判断の理由、失敗と学び |
| 高層 | 本部長、Director、VP | 事業に効くか、視座が高いか | 事業インパクト、市場観、5年後。**技術は語らない** |
