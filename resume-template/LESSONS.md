# LESSONS.md — 教訓の蓄積（時系列ではない知識ベース）

> **このファイルは意図的に空です。** テンプレートとして「他人の教訓リスト」を渡すと、あなたはそれを「従うべきルール」として扱ってしまい、自分で気づく機会を失います。渡すべきは教訓の中身ではなく、**教訓を蓄積する仕組みと習慣**です。使いながら、ここに自分の教訓を書き足していってください。
>
> **他ファイルとの違い**:
> - `SESSION_LOG_YYYY-MM-DD.md`（任意運用） = **その日に何が起きたか**（日ごとに増える、時系列の記録）
> - `LESSONS.md`（本ファイル） = そこから抽出した、**今後も繰り返し使える教訓**。日をまたいで累積する、**時系列ではない知識ベース**
>
> **運用**: 作業の節目（1日の終わり等）に、その日に起きたことを見返し、**他の応募先・他の場面でも再利用できる教訓**があれば本ファイルに追記してください。その日限りの事実（特定の案件の特定の数字等）は`input/`側の役割であり、ここには書きません。ここに書くのは「次に似た場面が来たとき、どう振る舞うべきか」という行動指針だけです。

---

## 教訓の書き方（型）

1つの教訓は、次の2つで構成してください:

- **何があったか**: 具体的に何が起き、なぜそれが問題だったか
- **だから何をすべきか**: 次に同じ場面が来たとき、どう振る舞うべきか（一般化された行動指針）

```
### N. （教訓の要約を一言で）

**何があったか**: （具体的な経緯）

**だから何をすべきか**: （次にどう振る舞うべきか）
```
