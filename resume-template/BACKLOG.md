# BACKLOG.md — 今すぐはやらないと判断した事項の記録

> **このファイルは意図的に空です。** 使いながら、「検討したが今回はやらない」と決めたことをここに記録していってください。
>
> **なぜこのファイルがあるか**: 「今回はやらないと判断した」ことと「検討していない」ことは別です。記録しないと、次に自分（あるいは一緒に作業するAIエージェント）が同じ検討を最初からやり直すことになります。**⚠️ 結論だけでなく、理由を必ず残してください。** 理由が無いと、後から誰か（未来の自分を含む）が「なぜこうなっているのか分からないから」と、良かれと思って元に戻してしまうことがあります。**結論と理由をセットで残すこと自体が、このファイルの最も重要な原則です。**

## 書き方の型

各項目は次の3点を書いてください:

- **なぜ必要か**: この対応をしないと何が問題か
- **なぜ今やらないか**: 今回見送る理由
- **いつ・どう対応するか**: 再検討するタイミング、対応する場合の方針

```
### N. （項目名）

**なぜ必要か**: （...）

**なぜ今やらないか**: （...）

**いつ・どう対応するか**: （...）
```

対応が完了したら、項目を削除せず「✅ 対応済み（日付）」を追記して残してください（削除すると「なぜそう決めたか」という経緯が失われます）。
