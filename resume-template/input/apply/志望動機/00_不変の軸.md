# 志望動機 — Layer①: 不変の軸（職種にも企業にも依存しない）

> **位置づけ**: 志望動機は3層構成で管理します。
> - **Layer①（本ファイル）**: 応募する職種・企業に関わらず変わらない、自分の一貫した資質・キャリアの軸・実績材料
> - **Layer②**（`ロール_{職種名}.md`）: 「なぜこの職種か」という、同じ職種の複数応募先に共通する論理。⚠️ **職種が違うと内容が矛盾するため（例: 「事業会社に行きたい」vs「引き続きコンサルを極めたい」）、職種ごとに別ファイルにする**
> - **Layer③**（`../06_志望動機_希望条件_{接尾辞}.md`）: 応募企業ごとの固有の事実・エピソード・希望条件（年収等）。応募先ごとに複数のファイルが共存します
>
> なぜ3層に分けるか: 情報の「更新のきっかけ」が層ごとに違うためです（`input/README.md`と同じ考え方）。Layer①はめったに更新しない、Layer②は職種の説明を磨くたびに、Layer③は面接で新しい事実が判明するたびに更新します。
