# 学歴・職歴（西暦で統一）

> 年は西暦で統一してください。和暦や表記ゆれがあると生成時に混乱します。

## 学歴
| 年月 | 内容 |
|---|---|
| ★yyyy-mm | ★学校名 学部・学科 入学 |
| ★yyyy-mm | ★学校名 学部・学科 卒業（学士 / 修士 等） |

## 職歴
| 年月 | 内容 |
|---|---|
| ★yyyy-mm | ★会社名 入社（事業内容: ★） |
| ★yyyy-mm | ★退職理由（転職理由は事実を歪めずポジティブ変換すること。前職批判は書かない） |
| | 現在に至る |

- 会社間の異動・転籍がある場合はここに1行で補記してください（グループ内転籍か、本人の意思による異動か等、経緯が事実として分かる形で）。

## 社内での役職遷移（履歴書には書かず、職務経歴書側で使用）

> 会社ごとに、役職・役割がどう変わっていったかを時系列で書いてください。職務経歴書の「マネジメント経験」欄などで使います。

### ★会社名1（★yyyy-mm 〜 ★yyyy-mm、計★年）
- ★yyyy-mm 〜 ★yyyy-mm: ★役職・役割

### ★会社名2（★yyyy-mm 〜 現在）
- ★yyyy-mm 〜 現在: ★役職・役割
