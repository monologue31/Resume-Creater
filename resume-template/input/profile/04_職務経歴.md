# 職務経歴（職務経歴書の本体）

> 会社ごとに「## 会社N: 会社名」、その中の案件ごとに「### 案件X: 案件名」という2段構成にしてください。
> 各案件は「背景・課題 → 施策（工夫した点） → 成果」の順で書くと、そのまま職務経歴書の記述に使いやすくなります。
> ⚠️ **顧客名は匿名化してください**（例:「大手金融グループ」「運輸会社」等の業種＋規模ラベル）。実名は`input/`を含むプロジェクト全体で扱わない方針を推奨します（匿名ラベルだけで案件は一意に区別できます）。
> ⚠️ **捏造しないこと。** 数字が無い成果は、無理に数字を作らず「何をどう改善したか」を具体的な動詞で書いてください。数字が欲しい箇所は分かる形で★を残してください。
> ⚠️ **帰属を明確にすること。** 「誰が設計・実行したか」「権限の範囲はどこまでか」を、特に強い動詞（統括した／設計した／責任を持った 等）を使う箇所で確認してから書いてください（`LESSONS.md`参照）。
