# templates/ — 再利用可能なモジュール一覧

このプロジェクト（実際の転職活動）を通じて確立した手法のうち、**他社への応募でも繰り返し使える部分**をモジュールとして切り出したもの。

> ⚠️ **これらは「叩き台」です。** 元の作成者が自分の転職活動で必要だったから作った手順・チェック項目であり、そのまま従うべき正解ではありません。項目を足す・削る・自分のやり方に書き換える、自由にしてください。**捏造しない／事実と解釈を分ける／input は正本で documents は取捨選択、という3原則（`documents/PROMPT.md`参照）だけは変えずに引き継ぐことを勧めます。**
> 判断に迷ったら、まず自分の`../LESSONS.md`を読み（使い始めた直後は空です）、該当する手順が必要ならここに来る、という使い分けを想定しています。

## モジュール一覧

| モジュール | いつ使うか | 内容 |
|---|---|---|
| [`推薦文ジェネレータ/`](推薦文ジェネレータ/README.md) | リファラル応募で推薦文を用意するとき | 紹介者との関係のヒアリング方法、判断フレーム、**内部検討用テンプレート＋送付用テンプレート（別ファイル）**、チェックリスト |
| [`模擬面接ジェネレータ/`](模擬面接ジェネレータ/README.md) | 提出書類が完成し、面接ラウンドに臨む前 | 隔離を徹底した面接官・分身エージェントのプロンプト型、ラウンド別の人格差分、①②③の分類フレーム、書類変更要否(A)(B)(C)の判定軸、報告方針、有効性の実証記録 |
| [`JD突き合わせ・経歴ヒアリング/`](JD突き合わせ・経歴ヒアリング/README.md) | 新しい応募先のJDを入手したとき | JD要求と経歴の突き合わせ、ヒアリング質問の作り方 |
| [`年収交渉フレーム/`](年収交渉フレーム/README.md) | 希望年収を検討する・年収交渉の準備をするとき | 市場データの集め方、最低ライン／本命／強気の3段階設定、OTE/base整理 |
| [`提出前チェックリスト.md`](提出前チェックリスト.md) | 応募書類一式を提出する直前 | `scripts/check.py`では拾えない人的判断項目の最終確認 |
| [`日次終了チェックリスト.md`](日次終了チェックリスト.md) | その日の作業が一区切りついたとき（提出の有無に関係なく毎回） | SESSION_LOGのアーカイブ判断、ファイル肥大化・事実重複の点検 |

## 各モジュールに共通する構成

- **README.md**: いつ使うか（トリガー）＋進め方＋原則へのリンク（`LESSONS.md`）＋記入例へのリンク
- **テンプレート.md**（フォルダ形式のモジュールのみ）: プレースホルダー入りの空欄テンプレート。**本プロジェクト固有の情報（本人の氏名・経歴・金額・応募先固有の事情）は含まない**
- **記入例**: このテンプレート単体には記入例を含めていません（個人情報のため）。実際に使う際に自分の`documents/output/md/`・`input/apply/`側のファイルを参照してください。
