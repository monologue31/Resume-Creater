# 渡すファイル一覧（隔離チェックリスト）

> 2026-08-06追加。**従来、隔離（README.md「⚠️ この仕組みの生命線は『隔離』である」）は主セッションが毎回プロンプトに書く記憶に依存していた。忘れれば漏洩する。** 本ファイルはラウンドごとにコピーして埋める固定フォーマットにすることで、記憶ではなく手順で漏洩を防ぐ。
> 使い方: ラウンドを実行する前に、下の「実行用チェックリスト」節をコピーし、`{{ }}`を埋めて、**全項目にチェックが入るまでAgentツールを呼ばない。**

---

## 固定ルール（毎回同じ・変更不要）

### 面接官エージェントに渡してよいもの

| # | 内容 | 具体的な取得元 |
|---|---|---|
| 1 | JD（求人票） | `input/apply/07_応募先.md` の該当箇所 |
| 2 | 提出書類2点 | `documents/output/md/職務経歴書{{接尾辞}}.md`／`documents/output/md/Resume{{接尾辞}}_en.md`（自身のReadツールで読ませる。渡す側が本文を貼らない） |
| 3 | このラウンドの位置づけ・面接官の役職タイプ | 1文で定義したもの（`判断フレーム.md`「ラウンドごとの人格差分」参照） |

### 面接官エージェントに絶対に渡してはいけないもの

- `interview/companies/{{応募先}}/rounds/*.md`（想定問答・戦略ファイル）
- ⚠️ **`input/apply/志望動機/`配下すべて**（`00_不変の軸.md`・`ロール_プリセールス.md`・`ロール_コンサルティング.md`等、解釈ファイル。2026-08-07、単一ファイル`06_志望動機_希望条件.md`を3層構成に再編したため対象が拡張）
- ⚠️ **`input/apply/06_志望動機_希望条件_{{接尾辞}}.md`（企業固有の解釈ファイル。応募先ごとに複数存在するが、どの接尾辞のものも渡さない）**
- `input/profile/*.md`（正本）
- `interview/companies/{{応募先}}/mock/`配下のいずれか（過去ラウンドの質問・回答・分析）
- `interview/companies/{{応募先}}/書類外材料一覧.md`
- `interview/companies/{{応募先}}/企業研究_*.md`（あれば）

⚠️ **複数応募先を並行運用する場合の追加リスク（2026-08-07・3層再編に伴い追加）**: `志望動機/ロール_{職種}.md`は**複数の応募先（例: 同じプリセールス職の別の会社）から共有される**ため、誤って応募先Xの模擬面接に応募先Yが使う職種のロールファイルを渡す、あるいはロールファイル自体を（本来渡してはいけないのに）渡してしまうと、**職種が矛盾する志望動機が同じ分身に混入する**事故になる。上記の通りロールファイルを含む`志望動機/`配下は面接官・分身どちらにも一切渡さないため、この事故は構造的に起きない設計になっているが、**渡すファイルを個別に指定する際は`志望動機/`という単語が入っていないか都度目視確認する**こと。

### 分身エージェントに渡してよいもの

| # | 内容 | 具体的な取得元 |
|---|---|---|
| 1 | このラウンドの質問リスト | `interview/companies/{{応募先}}/mock/raw/質問_{{ラウンド名}}_{{日付}}.md`（面接官エージェントの出力そのもの） |
| 2 | 提出書類2点 | 面接官エージェントと同じ2点（同様にReadツールで読ませる） |

### 分身エージェントに絶対に渡してはいけないもの

- 上記「面接官エージェントに絶対に渡してはいけないもの」の全て
- 質問リストを作った面接官エージェントのプロンプト・思考過程そのもの

## 実行用チェックリスト（ラウンドごとにコピーして使う）

```
### {{ラウンド名}}（{{日付}}）隔離チェック

面接官エージェントへ渡すもの:
- [ ] input/apply/07_応募先.md（JD該当箇所）
- [ ] documents/output/md/職務経歴書{{接尾辞}}.md（Readツールで読ませる）
- [ ] documents/output/md/Resume{{接尾辞}}_en.md（Readツールで読ませる）
- [ ] このラウンドの位置づけ・面接官の役職タイプ（1文）
- [ ] 上記「絶対に渡してはいけないもの」を1つも渡していないことを確認した

分身エージェントへ渡すもの:
- [ ] mock/raw/質問_{{ラウンド名}}_{{日付}}.md
- [ ] documents/output/md/職務経歴書{{接尾辞}}.md（Readツールで読ませる）
- [ ] documents/output/md/Resume{{接尾辞}}_en.md（Readツールで読ませる）
- [ ] 「書類に記載が無ければ正直に『記載がありません』と答える」指示を入れた
- [ ] 上記「絶対に渡してはいけないもの」を1つも渡していないことを確認した

両エージェント共通:
- [ ] run_in_background: false でコールドスタートさせた（親セッションの文脈を引き継がせない）
```

**全項目にチェックが入って初めてAgentツールを呼ぶこと。** 1つでも未チェックのまま実行した場合、この仕組みの前提（隔離）が崩れ、模擬面接の結果は信頼できない。
